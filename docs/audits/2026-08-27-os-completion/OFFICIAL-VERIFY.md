## Bounded source gaps

1. **Bayzat:** require tenant/provider contract before replacing CSV.
2. **Ads:** read-only adapters are bounded contracts; exact Meta/Google account operations were not selected for this milestone.
3. **Composio tool operations:** webhook verification is evidenced, but exact connected accounts, auth configs, trigger types, and tool slugs require live project discovery.
4. **Provider plan eligibility:** Apollo, Hunter, NeverBounce, Google restricted scopes, Inngest, Sentry, and Resend depend on account/plan state that documentation cannot prove.
5. **Production topology:** repository evidence supports Next.js/Vercel/Supabase, but current team/project/branch, deployment SHA, backups, and runtime environment require control-plane readback.
6. **Apollo People Match idempotency:** no provider request-idempotency contract was found in the exact operation reference. The fixed local receipt prevents automatic duplicate spend but still requires provider-usage reconciliation after an uncertain response.

Where an exact operation is missing, the implemented fallback is inactive/mock, read-only, CSV, or explicit `UNVERIFIED_INTERFACE`; no private endpoint or scraped browser session is substituted.
